### 2.2 Regional Linguistic Nuances & Keyword Localization (EN vs. AR)

- **Egypt Single-Window Vernacular:** Egyptian traders frequently omit the formal phrase *«نظام التسجيل المسبق للشحنات»* in favor of colloquial and phonetic searches: *«رقم الاسيد»*, *«اسيد كارجو اكس»*, or *«منظومة نافذة»*. Backlog topics addressing Egypt must blend official legal references (Decree 38/2021) with conversational phonetic spellings.
- **Saudi & Gulf Platform Branding:** KSA search demand is heavily platform-branded. Searches focus on *«منصة سابر»*, *«منصة فسح»*, and *«بوابة زاتكا»*. Queries strictly differentiate between Product Conformity (`PCoC` / *«شهادة مطابقة المنتج»*) and Shipment Conformity (`SCoC` / *«شهادة مطابقة الإرسالية»*).
- **The 12-Digit HS Paradigm Shift:** As GCC nations transition from 8-digit to 12-digit integrated tariff codes, exporters search for both *«الرمز المنسق 12 رقم»* and English phrases like *"GCC 12 digit HS codes"* to resolve customs declaration rejections.
- **Incoterms Terminology:** Latin acronyms (`FOB`, `CIF`, `DAP`, `DDP`, `EXW`) are universally embedded within Arabic syntax (e.g. *«الفرق بين فوب وسيف في الشحن البحري»*). Content must feature both the Latin acronyms and MSA descriptions (*«شروط التجارة الدولية إنكوتيرمز 2020»*).

```typescript
import type { Metadata } from 'next'

export async function generateMetadata({ params }: { params: { slug: string } }): Promise<Metadata> {
  const post = await getPostBySlug(params.slug)
  if (!post) return {}

  const canonicalUrl = `https://exvorta.com/insights/${post.slug}`

  return {
    title: `${post.title} | Exvorta Trade Insights`,
    description: post.metaDescription,
    alternates: {
      canonical: canonicalUrl,
      languages: {
        'en-AE': `${canonicalUrl}?lang=en`,
        'ar-AE': `${canonicalUrl}?lang=ar`,
        'ar-SA': `${canonicalUrl}?lang=ar-sa`,
        'ar-EG': `${canonicalUrl}?lang=ar-eg`,
      },
    },
    openGraph: {
      title: post.title,
      description: post.metaDescription,
      url: canonicalUrl,
      siteName: 'Exvorta',
      type: 'article',
      publishedTime: post.publishedAt,
      authors: [post.author?.name || 'Exvorta Research Desk'],
      tags: post.tags?.map((t: any) => t.name) || [],
    },
    twitter: {
      card: 'summary_large_image',
      title: post.title,
      description: post.metaDescription,
    },
  }
}
```
